## 实际交互

- 打开茶话室即显示 AI 开场脚本：“Hello，让我们今天来创造点什么吧！”
- 三个话题分别保留会话、草稿和示例播放位置。快捷需求只填入输入框，点击 @AI 后才发出请求。
- 可逐句播放示例，脚本推荐按钮跳到真实存在的版式／看图共创。
- 点击 @AI 直接发送当前问题、相关最近 8 条消息；看图只发送当前 600×800 预览。去除茶话和看图的独立授权勾选，按钮旁保留发送范围说明。
- AI 返回的模板 key 经过白名单验证，才显示真实模板入口。不能声称尚未发生的“已推送／已生成／已同步参数／已高清导出”。
- 产品可见中文品牌已改为“设计助手”；内部 XDP 命名和历史文件名保留，以免破坏接口、署名和资源引用。

## 取景修复

以前垂直位移只由照片溢出的高度计算，某些比例下溢出为零，滑杆就没有可见效果。现在左右／上下按画框比例独立移动，缩放范围为 50%–200%。可以露出底色，原图不变。

滑杆和步进按钮直接修改现有 SVG image 的 x/y/width/height，不重复解码大图。手机窄屏把预览放到控制区上方并吸顶。增加上移、下移、放大、缩小和复位按钮。

## 在线接口

用户密钥只写入 Git 忽略的项目 `.env`，没有写入源码、HTML、文档或浏览器。

通过银河智算能力列表、模型权限和价格端点检查：本次密钥仅允许 `tt-6.1-sol`。因此文字和看图都使用其 OpenAI 兼容协议；没有反复调用未开放的 Flash 模型。上游模型名是服务商提供的标签，不做独立模型身份认证声明。

`node scripts/serve-studio.cjs` 在 Node 支持 loadEnvFile 时自动读取项目 `.env`。本地演示端口为 8774。不要将带密钥的 `.env` 放入公开仓库、静态托管或分享 HTML。

## 上线状态

本地已接入真实银河请求；`127.0.0.1:8774` 不是公网网址。本机已有 Vercel 凭据经官方 API 返回 invalidToken，尚无可用服务器／托管入口。没有声称公网或国内网络验收已完成。后续需要用户提供可用部署环境，再配置 HTTPS、同源反向代理、访问范围和调用限额；不应把当前仅允许本机访问的开发服务直接裸露公网。
