# 四场景助手实施计划

本轮以四个场景作为主要导航：茶话室、看图共创、轻参与、决策间。Tips 基地作为场景内知识入口；原有灵感池、模板、编辑器、评审和历史讨论保留为辅助资料，不再抢占主路径。

1. 茶话室：用户主动开启生日/日常话题；本地引导明确标识；可分享 HTTPS 来源链接；AI 只处理授权的当前话题；收束草稿可修改，确认后才加入灵感池，新发言使旧总结失效。
2. 看图共创：上传/引用已有图片，明确 @AI；本地可真正套进两种图片框，移动裁切与缩放；在线看图单独授权才传图；无图片不伪造分析；保留原图，确认才发布草稿，可继续原有二创。
3. 轻参与：照片/祝福+自选元素，原位预览；确认后新增署名贡献；一次贡献只反馈一次「共创默契」，与明星真实亲密度无关；尊重 reduced-motion。
4. 决策间：单稿、单变量的加减实验；原图/修改后切换；方向 Bingo 与保存 Bingo 分开；新版本不覆盖原作者，主办定稿不被越权；有可读版本记录与原稿返回。

沿用露紫、粉蓝奶油辅助渐变；不出现配色来源说明。无业务弹窗，无拖动才能浏览的控件，普通选择、勾选、滑杆只更新局部 DOM。数据仅当前页面内存，明确未连接真实群聊。离线可排版与记录，在线调用失败不伪装成功；密钥只在服务端。

验证：纯逻辑/接口授权及错误测试；保留既有 63 项回归；真实浏览器完成四条路径和 390px/320px 响应式检查，不冒充 iPhone 实机验收。
