# 逐步启发与收集灵感

## 本轮依据

甲方提供的「灵感冒险岛 · 提交灵感游戏化流程图解」：
https://www.workbuddy.link/p/U5QZTWdPH5QwDpwhG7H9Ge?source=2

已从用户打开的 Chrome 页面读取「产生灵感、共创形式、用户分层、对话要求」四个框架页签。页面是流程示例，不是真实产品数据。本轮采用其逐轮收敛、单人/多人双通道、贡献留来源的结构，保留当前设计助手的品牌与视觉，不照搬岛屿游戏皮肤。

以本次用户要求为准做两项调整：
- 「没有想法」不直接推向起稿，先给用途起点，再用情绪板或用户自定义的词确认感觉。
- 三类明确为「我有明确想法」「有想法，但不会动手」「还没有想法」，由用户选择，可随时重选；不做隐藏的人群画像推断。

## 可以操作的流程

1. **选择参与状态**。有明确想法的人少绕路；不会动手的人按小步骤拆解；无想法的人从一句话或一个起点开始。
2. **先说用途 / 已有想法**。首条消息不自动联网找参考，不推荐一整套成品方案。
3. **再确认感觉**。提供温柔纪念、舞台能量、轻快日常三张原创色彩与留白示意。它们不是照片参考或定稿；不喜欢时可直接用自己的词描述。有明确想法的人可以跳过，也可以主动回来看。
4. **确定必留与避开**。一次只问一个问题，不把所有表单一次塞给用户。
5. **确认方向与用图状态**。用途、感觉和必留/避开均可直接修改；已确认后也可重新编辑，修改会取消旧确认；选择「仅探索」也可保留方向。确认不等于公开发布或搜索，声明有授权也不等于系统已核验权利。
6. **主动收集**。用户决定是否分享到公共灵感池、是否在在线模式下找图片参考。参考保留作者、许可和原页链接，不伪装成已经导入的可编辑图片。
7. **从池中多选真实图片拼贴**。每张独立移动、缩放、旋转和矩形取景，原图不变。选择不记采用，保存稿件才记录来源与贡献者；SVG 元数据保留来源 ID。首次导入会在画面内排开，原有已编辑的图层不被重排。
8. **按细项比较稿件，意见重新入池**。整体感觉、配色、构图与留白、字体与文案、图片与装饰元素五个细项。每条意见带稿件来源、分类和署名，不自动改图，也不代替大家定稿。

## 群聊和私聊

- 当前群聊、当前成员私聊分别保存消息、未发送草稿、话题和引导状态。
- AI 请求只包含当前频道最近 8 条上下文。切换频道不携带另一边的聊天。
- 群聊的「从聊天里找新灵感」只使用群聊真实发言；AI 建议单独标为待讨论提议，保留来源消息，不伪装成全体共识。
- 私聊只有点击「确认分享到公共灵感池」才把确认后的方向公开到本页公共池；原私聊记录不随卡公开。
- 语音在切换频道时取消；切换演示成员后的旧语音结果也不能进入新成员草稿。

## 接口变化

`POST /api/scenes/reply` 增加 `channel` 与 `guidance`。后端只接收经过截断、枚举校验的状态字段，不接收完整前端会话树。

~~~json
{
  "mode": "tea",
  "channel": "private",
  "goal": "想做一张周末聚会海报",
  "consent": true,
  "messages": [{"id": "u1", "role": "user", "text": "想做一张周末聚会海报"}],
  "guidance": {
    "audience": "guided",
    "stage": "feeling",
    "intent": "周末聚会海报",
    "confirmed": false,
    "nextQuestion": "你希望它带来什么感觉？"
  }
}
~~~

- audience：ready / guided / explore。
- stage：intent / feeling / details / confirm / collected。
- 确认前不返回可点击模板推荐；首轮与普通对话不自动搜索。
- `/api/references/search` 在携带引导状态时，要求 collected、confirmed=true、referenceRequested=true，并继续要求本次 consent。
- 独立检索接口保留其他页面的兼容用法；界面没有在后台偷偷触发此接口。
- 私聊不能请求群聊 spark；服务端仍不保存聊天或替前端猜测身份。

## 已验证

**174 项自动测试通过，单文件构建成功。**

- 自动回归覆盖三类人群路径、初始无情绪板/无检索、频道与成员草稿隔离、确认不发布、本地模式零网络、真实来源提议、多图来源、独立取景、反馈分类、重复保存及旧上传 ID 冲突。
- 已在真实浏览器用无个人信息的合成图片走完：上传两图 → 灵感池勾选 → 自由拼贴 → 单独取景 → 留稿 → 按配色反馈 → 收回灵感池。发现并修复旧上传编号与种子卡片编号冲突的问题，保留原种子记录。
- 桌面与 390×844 模拟视口验证：无横向溢出，输入与发送可见。真实手机软键盘、麦克风仍需设备验收。
- 使用合成的聚会海报问题，真实文字模型返回 HTTP 200、engine=online，仅追问感觉，references=0、templateKey=null；没有把本地规则或模拟上游结果当成真实 AI 成果。

## 尚未完成的生产能力

本轮是既有本地演示上的可操作原型与网关逻辑更新。群聊不是跨设备实时聊天室，私聊也不是经过服务端账户权限保护的正式私密会话；没有数据库、长期保存、邀请入群、跨设备同步或成员鉴权。刷新仍会重置。新增界面文案和接口说明不将其表述成已上线的生产能力。

代码提交与公网部署是独立步骤：GitHub main 的更新不代表线上界面已部署。公网旧版本和本机新版本应区分验收，本轮尚未更新公网部署。
