## 实际变化

- 茶话室改为共创聊天室：消息、AI 回复、参考卡和讨论收束都留在同一个聊天流。整理讨论／去试图在顶部；话题、示例、手动参考链接与模式设置收进设置面板。
- 输入、语音和发送位于同一底部区域。消息增加不会把发送按钮推到页面下方；只有消息区滚动。
- Enter 发送，Shift+Enter 换行；isComposing 和 keyCode=229 期间不发送，防止中文候选词确认误发。
- 空草稿和请求中不能重复发送；AI 回复时可以继续编辑下一条草稿，完成后不会抹掉新输入。
- 讨论收束仍保留原始用户消息 sourceIds，用户确认才入池，不把示例发言当成真实成员共识。

## 浏览器语音

- 仅在点击语音按钮后创建并启动浏览器识别；不录制／上传 WAV，不依赖 XDP_VOICE_MODEL 或 /api/voice/transcribe。原服务端音频接口仍保持 off。
- 识别文字填入当前草稿，不自动发送、不自动生成作品。累积结果不会重复拼接；文字手动编辑后不会被旧识别覆盖。
- 取消、换页、切换话题或发送时会终止当前识别，旧回调不会覆盖下一次输入。识别最长 60 秒。
- 浏览器识别服务可能联网；不能把它称为保证离线的本机识别。不支持、拒绝权限、无麦克风、无语音或网络失败时显示具体说明并保留草稿。
- 当前浏览器界面曾出现语音服务连接失败；本轮没有把此环境的真实麦克风识别标为成功，也不回退到收费上传转写。
