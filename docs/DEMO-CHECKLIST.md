## 建议顺序

1. 茶话室：点浅紫米白示例，再点 @AI；等待真实回复与来源卡。不要连续点击。
2. 看图共创：准备一张自己的 JPG / PNG / WebP（小于 8 MB），上传后试「上移」「放大」，修改标题。
3. 点「确认留为稿件」，再进入决策间。
4. 只修改一个变量，先确认方向 Bingo，再另存新版本。
5. 下载 SVG 预览；在打开新页面前先保留文件。
6. 极简拼图：改一句祝福、切换边框、拖动元素，再确认留下心意。

## 演示时注意

- 作品、聊天和稿件仍是当前页面内存；刷新页面会清空，不是云端多人同步。
- 在线响应受现场网络和上游服务影响。今天单次文字／看图／参考检索各约 10–13 秒，不能保证每次同样快。
- 遇到网络不稳定，可将助手模式改为「本地引导 · 不联网」，或使用离线单文件继续排版演示；请明确它是规则引导。
- 语音输入现使用浏览器原生识别；首次点击可能需要麦克风权限。当前浏览器语音服务曾连接失败，现场先试，失败时直接输入文字；不再上传录音调用付费转写。
- 云端未安装自动抠图模型，该按钮已禁用；可演示纯色去背景与手动擦除。
- 参考卡保留出处，点开后仍需核对内容和版权；检索失败不会编造链接。
- 正式网址不依赖这台电脑一直开机；本机 8775 备用服务则依赖电脑和 Node 进程。不同地区、校园或手机网络仍应在现场提前试一次。
