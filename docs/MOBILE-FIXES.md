# 手机反馈修复与能力边界

## 修复

1. 评审卡片误继承白板 `touch-action: none`，现只在真正的画布操作中限制手势；评审卡片、SVG 和图片允许纵向滚动与缩放，手机禁用卡片入场动画及固定栏模糊，默认静态背景。
2. 旧二创的颜色按钮仅改变状态且全量重建面板。现在使用页内编辑，颜色输入与模板快捷色直接改变实际 SVG；保存时存下实际图稿、来源、图层和坐标，不再仅存预设 ID。虚假的人物正面/侧面动作及 AR 开关已从二创移除。
3. 人物与贴纸可上传、定位、缩放、旋转、镜像、置顶和删除；默认仍可滑动，明确进入移动模式后才捕获图层拖动。擦除只在用户展开的修边画布内生效，原文件保留，可恢复和撤销。
4. 自己的讨论气泡与昵称靠右，贴近自己的头像；不会再出现头像在右、气泡仍留在左边的错位。

## 人物抠图

- 离线支持透明 PNG、去除连通的纯色背景、手动擦除/撤销。
- 模型去背景需要服务版：Node 接收图片，Python / ONNX Runtime 在本机运行 U2NetP，不将照片交给外部模型平台。默认最长边 1600px，原图留在页面内存。
- 模型来源： https://github.com/xuebinqin/U-2-Net 与 https://github.com/danielgatis/rembg 。安装器校验官方 U2NetP 下载指纹，模型文件不纳入 Git。许可见 licenses/U2NET-LICENSE.txt。
- 自动前景分割不是人物动作生成，也不保证所有背景与发丝边缘。当前端没有模型时不显示“处理成功”，应使用手动修边或安装模型。

## 语音：从浏览器演示改为录音转写

- 不再依赖浏览器 SpeechRecognition 的可用性。服务版采用 MediaRecorder / 选择录音文件，转换真实 PCM WAV，再向 `/api/voice/transcribe` 提交。
- 页面先告知录音发送给银河智算，并单独获得授权；服务端再次检查授权、音频格式、长度、余额与请求次数。密钥不下发到浏览器。
- 转写只是填回需求框；用户仍须检查后点击生成，不自动执行录音中的指令，也不自动发布。
- 当前离线文件 `file://` 无在线转写：明确禁用并提示需要服务版。手机公网使用还需要部署有鉴权的 HTTPS 服务，这不是打开单文件或上传 GitHub 就能获得的能力。

## 验证证据

- 63 项自动测试通过；包含真实色值变更、图层坐标持久化、原稿不变、保存去重、语音授权、录音取消、WAV 格式校验、实际音频转发与服务失败。
- 真实转写请求：4.7 秒本机生成的合成测试录音，HTTP 200，返回“请把海报背景改成紫色，加一朵小花。”；没有采集或发送用户的实际录音。
- 本机模型测试：合成测试图片 → HTTP 200 → RGBA PNG，透明通道确实变化；不是用状态文字代替处理。尚未使用用户的人物原图验收复杂抠图质量。
- 浏览器中自定义背景 `#FFDDAA` 确实出现在预览和保存后的新稿 SVG 中；添加的爱心及位置修改保存后仍在，原稿没有变化。
- 自己的测试气泡右边缘与右侧头像间距 12px；390px 页面无横向溢出。
- 已检查评审卡片 computed touch-action 为 `pan-y pinch-zoom`，原生键盘滚动可连续跨卡片；当前工具不能向 iPhone QQ 浏览器注入真实手势，不能据此声称已完成该设备实机验收，请使用新文件在原设备复测。

## 参考灵感勾选闪烁修复

- 原因：参考素材与文字授权的 change 事件仍调用 `paintAssistant()`，替换整个工作区并重新触发桌面入场动画，素材还会按选中状态重新排列。
- 修复：两类复选框只更新已有节点的选中数量、授权提示、方案失效状态与生成按钮；不替换工作区或素材列表。更改参考素材仍撤销旧的文字发送授权，语音授权独立保留。
- 新增两项回归测试：禁止勾选事件调用整页渲染；验证计数、取消授权、方案失效及服务未连接/处理中/录音中的按钮保护。
- 浏览器验收：桌面连续勾选保持原复选框焦点；390×844 视口连续取消/勾选同一素材，工作区 scrollTop 均为 536.67px，素材顺序与展开状态不变，无横向溢出。在线文字授权切换即时更新按钮，未调用生成服务。
