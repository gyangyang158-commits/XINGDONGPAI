## 选中的方向

| 来源效果 | 适用位置 | 本项目实现 |
| --- | --- | --- |
| MeshGradient | 项目概览与工作区的背景 | 自行编写的 WebGL2 六锚点柔和混色、慢速漂移和很小的指针偏移；露紫主调，柔粉、雾蓝、奶油色辅助 |
| FilmGrain | 背景的轻微材质感 | 固定的低强度暗部加权噪声；不逐帧跳动，不作用于作品图片 |
| Sparkle | 大块留白的少量点缀 | 四个 CSS 星芒缓慢呼吸，不使用上游高亮采样、双网格和光晕实现 |

另外给概览海报外框加了一次性的悬停扫光，不在内容区循环播放。没有使用 Glitch、CRT、像素溶解、全屏液态扭曲或密集粒子，避免妨碍阅读。

以上是**参考上游视觉方向后的本地轻量实现**，不是上游组件的直接接入或逐像素移植。上游采用 WebGPU/TypeGPU，本项目仍为原生 HTML/CSS/JavaScript；没有安装或打包其运行库，也没有其遥测代码。此文档不把本项目效果宣传成官方 Shader 组件。

## 边界与预算

- 单独的背景 canvas，`aria-hidden`，整层 `pointer-events: none`；不会拦截选图、表单、语音或评论操作。
- 桌面绘制上限 20 fps、65 万像素；小屏上限 12 fps、28 万像素，不按高 DPR 无限制放大。
- 标签页隐藏、手动暂停、系统减少动态效果、省流量或高对比度模式时停止持续绘制；恢复可见后时钟不会突然快进。
- WebGL2 不可用或上下文丢失时显示本地静态 CSS 渐变，不让业务页空白。减少动态效果模式保持静态氛围，不播放星芒与悬停扫光。
- 暂停偏好只在本机保存一个布尔状态，不记录指针位置、图片或个人内容；没有新增外网请求。
- 顶栏“动效 / 静态”是原位开关，不打开设置弹窗。它仅控制背景动效，不禁用已有必要交互反馈。

## 文件

- `assets/effects/atmosphere.js`：GPU 渐变、播放控制、回退与用户开关。
- `assets/effects/atmosphere.css`：静态回退、星芒、一次性悬停扫光与文字对比度。
- `tests/atmosphere.test.cjs`：播放时钟、节流、降低动态效果、降级和许可打包测试。

## 验证范围

浏览器实际确认 WebGL2 渲染成功、开关切换正常、减少动态效果模拟状态停止动画。1440 × 1000、390 × 844 与 320 × 740 布局检查没有页面横向溢出。GPU 丢失、省流量与后台播放的策略由单元测试覆盖，未宣称在每类真实显卡或实体手机上完成压力/电量测试。
