## 确认的问题与修正

通过当前应用截图确认：预览内仍显示“上传你的照片”的占位块，但三个滑杆可被拖动并改变数值。该状态没有图片可移动；此前只验证有图片状态，没有覆盖这个空状态。

现在：
- 无有效图片时 fieldset、三个 range 和步进按钮禁用，预览下方明确提示先选图。
- 图片读取／解码中保持禁用；成功后恢复居中 100% 并显示当前文件名；失败保留先前可用图片并显示错误。
- 另外修正上传竞态：原先标题等编辑共用 revision，会使正在解码的照片被当作过期请求丢弃。现在图片上传使用独立 uploadToken；解码过程中编辑标题不会取消上传或导致控件永久锁住。
- 忽略空状态下伪造的 range 事件，不允许状态与画面继续脱节。
- 有图片时仍原位更新实际 SVG image 节点；保存／下载从同一状态生成几何参数。
- 保留最新主线的极简拼图拖动、字号、画框功能。
