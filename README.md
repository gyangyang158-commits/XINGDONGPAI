# XINGDONGPAI · 星动派共创工作室

面向小组的视觉共创原型：收集灵感、整理方向、成员投票、稿件评审与主办确认。已提供仅监听本机的 AI 调用网关；仍没有真实账号、业务数据库或在线多人同步。

## 打开

直接用浏览器打开 `xingdongpai-room-optimized.html` 即可。请保留同级 `assets/` 目录，其中包含视觉层、逻辑层与本地字体。

也可以启动仅监听本机的预览服务：

```sh
node scripts/serve-studio.cjs
```

访问 `http://127.0.0.1:8772/xingdongpai-room-optimized.html`。

## 边界

图片与草稿默认保存在当前页面内存，刷新后丢失；主动调用模型抠图时，图片会发送给本机服务处理，不交给第三方模型服务商。录音仅在单独授权后发送至转写服务。角色切换仅供演示，前端隐藏票数不是安全保密机制。正式上线需要服务端账号权限、投票与审计、素材授权、持久化、真实原图交付和隐私方案。旧 AR、拼车等附加功能仍是演示，不能当成已上线服务或交易。

### 两种执行方式

1. **离线整理**：实际读取已勾选的素材文字，执行版式匹配并生成 SVG 预览；不调用语言模型。标题、副标题可编辑，只有点击“加入灵感池”才发布。确认后的结构化方案计为一张版式灵感卡。
2. **在线 AI**：服务端读取密钥，检查余额后请求语言模型，验证 JSON 输出，再执行本地 SVG 排版工具。浏览器默认使用离线模式；在线调用须勾选本次文字发送授权。只发送需求和勾选素材的 ID、标题、说明、分类及是否有原图，不发送图片二进制、署名或群聊。不冒充抠图、人物生图或印刷交付。

密钥只放在服务进程环境或仓库外的私密文件。PowerShell 启动示例：

```powershell
$env:XDP_AI_KEY_FILE='D:/private/provider.env' # 文件中为 API_KEY=自己的密钥
$env:XDP_AI_MODEL='deepseek-v4.1-flash'
node scripts/serve-studio.cjs
```

也可设置 `XDP_AI_KEY`，无需额外文件。`.env.example` 仅作为配置说明，不会自动加载；不要提交真实密钥。默认网关服务商为银河智算；模型名为其目录标识，不据此独立认定底层模型身份。服务监听 `127.0.0.1`，禁止跨源浏览器请求；每分钟最多五次且同一时刻只处理一次 AI 请求。这只是本机开发网关，不能直接作为公网服务部署。

### 语音输入与朗读

当前使用真实录音转写链路：`MediaRecorder` 录音或选择音频文件 → 浏览器转换为 16kHz 单声道 WAV → 服务端音频模型转写 → 回填需求文本。最长 60 秒，结果可修改，不会自动生成或发布。服务商为银河智算，需单独授权发送本次录音，密钥只在服务端。默认模型目录标识为 `gem-3.5-flash-lite`，可通过 `XDP_VOICE_MODEL` 修改；不据此独立认定底层模型身份。

**手机直接打开 `file://` 离线 HTML 时，在线转写不可用。** 页面明确提示使用服务版，不再用浏览器 `SpeechRecognition` 属性存在冒充语音已可用。本机 `http://127.0.0.1` 可测试；手机要联网使用，需要另行部署有鉴权的 HTTPS 服务，本项目当前的环回网关不能直接当公网服务。GitHub 上传代码不等于部署了转写后端。

录音必须由用户点击并授权麦克风；取消、切页或隐藏页面会停止采集。浏览器不能录音时，服务版支持选择已有录音文件。失败显示真实错误，不伪造识别结果。方案朗读只使用本机中文语音，不自动把文字交给远程朗读服务。

当前完整自动测试为 63 项。已用虚构文字需求跑通一次真实模型请求；录音转写已用一段 4.7 秒合成中文测试音频验证，返回原句；仍未在用户手机的真实麦克风上实录验收。
